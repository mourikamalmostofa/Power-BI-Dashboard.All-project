📊 HR Analytics Dashboard (Power BI)

This project presents an interactive HR Analytics Dashboard built using Power BI to analyze employee data and uncover key workforce insights. The dashboard helps organizations understand employee distribution, attrition trends, and workforce demographics to support data-driven HR decisions.

🔍 Key Features:
Employee Overview
Total Employees: 1,417
Active Employees: 1,186
Attrition Count: 231
Attrition Rate: 16.3%
Demographic Insights
Age Group Distribution
Average Age (36.94 years)
Gender-based attrition analysis
Department Analysis
Attrition count by department
Department-wise employee distribution
Salary Insights
Attrition trends across salary ranges (0–3 LPA, 3–6 LPA, etc.)
Job Role Analysis
Attrition based on job roles and job satisfaction levels
Experience Analysis
Attrition patterns based on total years of experience
🎯 Objective:

The main goal of this dashboard is to:

Identify factors influencing employee attrition
Analyze workforce distribution across departments
Provide actionable insights for HR teams
🛠 Tools & Technologies:
Power BI
Data Visualization
Data Cleaning & Transformation (Power Query)
📌 Insights Gained:
Higher attrition observed in certain salary bands and job roles
Majority of employees fall within the 26–35 age group
Department-wise imbalance in employee distribution
